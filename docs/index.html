ゲームで使うには

  1. ZIPをresourcepacksフォルダーに入れ、パックを有効にします。
  2. コマンドをコピーして、Minecraftで実行します。

プレビューは描画倍率1×が基準です。チャットの倍率やTitleの拡大がある場合は表示サイズが変わります。文字送り・行間は変わりません。他のtext.vshを書き換えるパックと併用すると競合します。

色の仕組みと、影の指定

本体は#FEssyy、影はARGBの0xFFFDssyyを使います。ssがサイズ、yyがYオフセット＋128です。64×64のスキンと顔・帽子のUV条件内でだけ解釈します。本体を白、影をRGB各63/255へ戻し、アルファは維持します。

影なしはshadow_color:0。通常文字のフォントアトラスは対象外です。プレビューはゲーム内のクリッピングや描画順まで再現するものではありません。
